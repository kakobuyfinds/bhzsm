How to use the HipoBuy spreadsheet

  1. Check the source listing. Open a CAFANS product and locate the original marketplace link. In HipoBuy, check whether the agent accepts that link and loads the product options.
  2. Confirm size and color. Compare garment measurements with an item you already wear. For shoes, check whether the chart uses foot length or insole length. Save the variant name and size chart with your shortlist.
  3. Review warehouse QC photos. When photos are available, compare the color, size label, stitching and visible condition with your selected listing. Request a close-up or measurement if the supplied photos leave an important detail unclear. Check the exchange window before approving shipment.
  4. Compare shipping quotes. Use the same destination and packed parcel for each quote. Check whether the route charges by actual or volumetric weight and which taxes or handling charges are included.

HipoBuy spreadsheet FAQ

What is a HipoBuy spreadsheet?

It is a directory of products and source links you can use to build a shopping shortlist. This independent directory lists twelve CAFANS products and links to their detail pages.

Can I paste a CAFANS page into HipoBuy?

Open the CAFANS product page and look for the original marketplace URL. Use that original URL in HipoBuy if the agent supports it, then confirm it opens the correct item and variant.

Do the product prices include international shipping?

The table shows estimated item prices. Add domestic delivery, international postage and any applicable fees or taxes to compare order totals.

Where can I find QC photos?

Check the warehouse section of your agent account after the item arrives, if your order includes QC. Compare photos of your own item with the listing and the variant you selected.
